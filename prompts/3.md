*Yêu cầu chỉnh sửa liên quan đến Role
System Admin và Supper Admin : mới được xem nhật ký hệ thống của tất cả các user
Admin : chỉ xem được nhật ký hệ thống của bản thân tài khoản và tài khoản khách hàng mà họ quản lý
System Admin có thể tạo được tài khoản là Supper Admin
Supper Admin có thể tạo được tài khoản là Admin và Customer :
* Lưu ý Supper Admin khi tạo tài khoản loại :
  - Admin : 
      + Có thể chọn các khách hàng và gửi cho họ quản lý
	  + 1 Admin có thể quản lý nhiều khách hàng (Admin chỉ nhận được thông báo và phê duyệt hoặc từ chối từ các khách hàng mà họ quản lý)
  - Customer :
      + Có thể chọn Admin để quản lý khách hàng này (1 khách hàng chỉ có thể quản lý bởi 1 Admin, Khách hàng thi thao tác thêm camera hoặc sửa thông tin quan trọng từ camera chỉ gửi thông báo đến Admin mà họ quản lý, nếu không có Admin mà họ quản lý thì gửi đến Supper Admin)
	  + Trường hợp tạo tài khoản khách hàng mà không chọn Admin nào quản lý thì vài trò quản lý thuộc về Supper Admin (Supper Sẽ đảm nhận mọi vai trò với khách hàng giống y hệt Admin quản lý khách hàng)
* Lưu ý Admin và Customer :
  - Ở dashboard và các màn hình khác => họ chỉ xem được data của bản thân tài khoản và của họ quản lý. (ví dụ tk admin1 quản lý customer1, customer2 => họ chỉ xem được data được thống kê bởi admin1, customer1, customer2)
* Lưu ý Supper Admin và System Admin :
  - Đối với Super Admin : xem được data của bản thân và của tất cả các tài khoản dưới cấp (Super Admin, Admin, Customer)
  - Đối với System Admin : xem được data của tất cả các tài khoản 
  - Đặc biệt quản lý data của nhiều tài khoản thì phải có chức năng filter để lọc tài khoản nào cần xem
