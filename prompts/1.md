# Thiết lập kiến trúc dự án: Traffic Camera AI

## Mục tiêu
Tạo toàn bộ cấu trúc folder, file cấu hình, và boilerplate code
cho hệ thống nhận dạng phương tiện giao thông qua camera,
đảm bảo có thể dễ dàng chuyển đổi giữa các nguồn camera
mà không cần thay đổi code xử lý.

---

## Yêu cầu kiến trúc

### Design pattern bắt buộc
Sử dụng **Adapter Pattern** cho camera source:
- Tất cả nguồn camera (public MJPEG, Android IP Webcam,
  IP camera thật) đều implement chung 1 interface
- Code xử lý (detection, OCR) không biết camera đến từ đâu
- Chuyển nguồn = chỉ đổi 1 dòng trong config, không đụng logic

### Môi trường cần hỗ trợ
- `dev`  : dùng camera public MJPEG online để test, không cần hardware
- `test` : dùng file video .mp4 local để test offline
- `prod` : dùng smartphone Android (IP Webcam) hoặc IP camera thật

## Yêu cầu chi tiết từng file

### `sources/base.py`
Abstract class với các method:
- `connect()` → bool
- `read_frame()` → tuple[bool, np.ndarray]
- `release()`
- `is_connected()` → bool
- property `source_info` → dict (url, fps, resolution)

### `config/base.py`
Dataclass hoặc dict với các key:
- `CAMERA_SOURCE`: loại nguồn ("mjpeg" | "file" | "rtsp")
- `CAMERA_URL`: URL hoặc path
- `FRAME_WIDTH`: 640
- `PROCESS_EVERY_N`: 3 (xử lý 1/N frame)
- `CONFIDENCE_THRESHOLD`: 0.4
- `ENABLE_OCR`: bool
- `ENABLE_TRACKING`: bool
- `ENABLE_LOGGING`: bool
- `LOG_PATH`: "data/logs/"

### `config/dev.py`
Override với 2-3 URL camera MJPEG public thật sự hoạt động
(ví dụ: Buffalo Trace factory, một camera đường phố công khai)
dùng để test ngay mà không cần hardware.

### `main.py`
- Đọc biến môi trường `ENV` (default: "dev")
- Load config tương ứng
- Khởi tạo đúng CameraSource theo config
- Chạy pipeline loop chính
- Xử lý graceful shutdown (Ctrl+C)

## Yêu cầu implement

1. **Tạo toàn bộ files** với code thật, không phải placeholder comment
2. **`sources/`** phải có đủ 3 adapter hoạt động được
3. **`main.py`** phải chạy được ngay với lệnh:
   ```
   ENV=dev python main.py
   ```
   Kết quả: mở cửa sổ hiển thị live stream từ camera public,
   chỉ cần OpenCV (chưa cần YOLO hay OCR ở bước này)

4. **`requirements.txt`** đủ và chính xác
5. **`.env.example`** có hướng dẫn rõ ràng
6. **`README.md`** có hướng dẫn setup và chạy từng môi trường
